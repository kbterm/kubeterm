people evaluating Kubeterm that real teams rely on it, and it tells us which platforms

## Add yourself

Pick whichever is easier:

- **Open a pull request** adding a row to the table above.
- **[Open an issue](https://github.com/kbterm/kubeterm/issues/new?template=adopter.yaml)**
  with the details below and we will add the row for you.

What to include:

- **Organization** — company, team or project name, linked to your website if you have one.
  Write `Anonymous` if you would rather not be named but still want the use case counted.
- **Since** — roughly when you started using Kubeterm (`2025-06` is precise enough).
- **Platforms** — macOS, Windows, Linux, iOS, Android.
- **How Kubeterm is used** — one short sentence, if you'd like to add one. Optional.

Anything you put here is public. Please don't include cluster endpoints, account IDs,
kubeconfig contents or anything else you wouldn't post in a public issue.

If you'd rather share privately, tell us on [Discord](https://discord.gg/Jv4zEEBMR2) instead;
we won't publish it.
